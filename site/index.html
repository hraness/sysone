a System 1.

Your agent asks small yes/no, choice, and score questions and gets validated answers with probabilities. You choose the model.

Switch models
from your config.

Agents make many small judgment calls: classify a message, pick the next task, check a condition. Sys1 sends each call to the model you chose and checks the shape of the answer, so your code gets the same format whichever model replied.

Choose who answers.

Choose a local model, enable hosted Jev, or register a compatible server. Pin the backend and model in configuration; local-only keeps decision requests on your machine.

Return answers your code can use.

Ask for yes/no probabilities, named choices, or numeric scores. Sys1 validates the response shape and requested model, rejects malformed results, and carries cancellation through the request.

Know what answered.

Model weights download only when you ask for them, for example with sys1 setup or sys1 pull. Each answer reports which backend produced it, and answers from built-in local models also name the adapter.

Three ways
to call Sys1

All three take the same request and return the same answer format. Use the client from Node or Bun, run the router inside a Bun app, or call the local daemon from any language that speaks HTTP.

Node & Bun client
@hraness/sys1/client

Typed requests, validated responses, and cancellation. Install without the optional native runtime.

Embedded Bun router
createRouter()

Routing and local models run inside your app. You pass the configuration and call dispose() when you finish.

Local HTTP daemon
POST /v1/systemone

A local-only endpoint, on 127.0.0.1 by default, for Rust, Python, and other languages. The CLI starts, stops, and checks the daemon.

Inside your applicationTypeScript
import { createClient } from "@hraness/sys1/client";

const sys1 = createClient();
const { response, metadata } = await sys1.evaluate({
  state: "The build failed after a dependency update.",
  questions: {
    next: {
      type: "choice",
      criteria: {
        repair: "Fix the build",
        continue: "Continue work"
      }
    }
  }
});

console.log(response.answers.next);
console.log(metadata.backend);

What Sys1
connects to

Sys1 has built-in support for Jev, TypeSafe’s hosted decision model, and for local Qwen models. You can also register a compatible server you run, such as OpenJev or Kev.

Install and set up a local model.

Build from source, then run setup. Setup downloads Qwen3 1.7B, and hosted Jev stays off until you turn it on. The docs cover the release install, local weights, and hosted Jev.

Local quickstart
git clone https://github.com/hraness/sys1.git
cd sys1
bun install
bun run build:dist
ln -sf "$PWD/dist/cli.js" ~/.local/bin/sys1
sys1 setup

Before you begin.

What is a typed decision?

A small judgment returned in a predictable shape: noul is a yes/no probability, choice selects one of your named options, and score returns a numeric result over your ordered criteria. Your app decides how to use it.

Can everything stay local?

Yes, for decision requests using local models and a local-only routing policy. Initial installation and explicit model setup download packages and weights. Hosted Jev is disabled by default.

Can I replace my existing Jev client?

Yes. Run sys1 jev enable, which turns on hosted Jev and sets routing to hosted-only so no request falls back to a local model. Pin jev-1.13.0 so your app keeps the same model while you switch to the Sys1 client. Test your request sizes, question limits, cancellation, and error handling. Evaluate local models separately before you allow fallback to them. Keep permissions and quality thresholds in your app. Read the adoption guide.

Does Sys1 pick the most accurate model?

No. You choose the model. Fresh setup uses Qwen3 1.7B; enabling Jev selects hosted-only operation. A hosted outage returns an error. Local fallback requires an explicit policy change after you evaluate it. Installing a smaller model does not change that selection. Sys1 does not estimate accuracy per request; evaluate the chosen model on your tasks.

What does it cost?

Sys1 is free, open-source software under the MIT license. Local inference uses your hardware. Hosted providers may charge separately under their own plans.
